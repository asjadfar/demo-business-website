# Demo Business Website — Golden Crust Bakery & Cafe

A modern, mobile-first 1-page business website, built as a demo of my web development work.

**Live demo:** https://asjadfar.github.io/demo-business-website/

## What it shows
- Sticky navigation with mobile menu
- Hero section with headline and call to action
- About section with business stats
- Menu with product cards and prices
- Photo gallery
- Customer testimonials
- Opening hours and working order form
- SEO meta tags (title, description, Open Graph)
- Fully responsive — designed mobile-first

## Tech
- Pure HTML + CSS + JavaScript (no frameworks, no build step)
- Images from Unsplash
